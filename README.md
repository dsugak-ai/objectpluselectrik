Приложение «Объект+» не собирает и не хранит персональные данные пользователя. Все данные (проекты, сметы, фото) хранятся локально на устройстве пользователя и не передаются на сторонние серверы.

Приложение использует аналитический сервис [Firebase Analytics / AppMetrica] для сбора обезличенных данных о событиях внутри приложения (открытие экранов, нажатия кнопок, факты покупок). Эти данные используются исключительно для улучшения продукта и не позволяют идентифицировать конкретного пользователя.

Пользователь может отказаться от сбора аналитики, удалив приложение.
