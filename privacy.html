Политика конфиденциальности приложения «Объект+ Смета электрика»

Настоящая политика описывает, как приложение «Объект+ Смета электрика» обрабатывает данные пользователей.

Какие данные обрабатываются

  • Локальные данные пользователя: проекты, сметы, фото, заметки. Они хранятся только на устройстве пользователя и не передаются на сторонние серверы.
  • Обезличенные технические данные для аналитики: идентификатор сессии, тип устройства, версия ОС, события внутри приложения (открытие экранов, нажатия кнопок, факт покупки). Эти данные собирает аналитический сервис AppMetrica и использует для улучшения продукта.

Цели обработки данных

  • Обеспечение работы функционала приложения (учёт работ, формирование отчётов, экспорт документов).
  • Улучшение пользовательского опыта, исправление ошибок, измерение конверсии и эффективности фич.

Передача данных третьим лицам

Данные, собираемые аналитическим сервисом, могут передаваться на серверы поставщика сервиса Яндекс в соответствии с их политикой конфиденциальности. Персональные данные (ФИО, телефон, email) приложением не собираются.

Хранение и удаление данных

Локальные данные хранятся на устройстве пользователя. Пользователь может удалить их, удалив приложение. Сбор аналитики можно прекратить, удалив приложение.
